## 5. Surprises
- QA tests are the main failure source: 11 of 17 escalations came from tests that contradict the issue or the
  page, or from test gaps only QA could close (non-unique queries, uppercase text, a fixture that already fits,
  older tests asserting the old UI, a bullet count that includes certificates). One QA re-run per task was not
  enough five times (#38, #11 twice, #42, #41).
- A session can emit several `result` events: a background subagent finishing after the verdict produced a
  second one, and the runner judged the stage on it (#11; fixed in 2982a5f).
- Playwright's web server lives in its own process session, so it outlived a role session that hit its turn
  limit and held port 4173 for the next task.
- Auto mode refused QA's one-line exemption in an e2e origin check as weakening oversight (#44). The role stopped
  correctly; the cleaner test renders the case without the mocked AI call.
- Strict "branch up to date" rules turn every owner batch merge into a chain of BEHIND PRs.
- The CI gitleaks step scans every branch, so one false positive on one branch failed every PR.
- Spec gaps showed up only when the owner looked at the running site (first screen, data model, visual levels);
  brief v5.2 and v6 reworked the flow twice in one day.
- The operator's own errors: a cross-language rule turned into an issue without a question (#36), and an issue
  that named paths the builder cannot write (#42).

## 6. Reusable practices
- Fast-forward the product clone's main before every cycle, and name `origin/<base>` in prompts: compliance
  then sees only the task's diff (evidence: #6 flagged #5's merged email before this).
- Commit before any mutation check; the helper restores files with `git checkout`.
- When a task escalates on a wrong test, quote the builder's Test-defect line on the issue and restart with a
  one-line test note; it passed first time for #8 and #38.
- Embed exact assets (SVG) in the issue with their SHA-256, and check the hash on the posted issue: roles cannot
  read the operator's folder.
- Stop a queue between tasks by watching for the `state` event that follows `terminal` (labels are written by
  then), never on `terminal` itself.
