## 5. Surprises
- R-04 cannot hold literally: `brief-D2.md`, `factory-spec.md` and `kickoff-D2.md` contain the
  bypass flag because they forbid it, and agents may not edit them. The grep test exempts exactly
  those three files (`docs/failures.md`).
- Claude Code 2.1.331 does not list `--max-turns` or `--append-system-prompt-file` in `--help`, but
  both parse. The live call showed `permission_denials` (array) and an extra `safety_stops` (number)
  on the result event. The runner counts both as blocked actions.
- The latest TypeScript is 7.0.2, but typescript-eslint 8.74.0 requires `<6.1.0`. Pinned 6.0.3.
- pnpm 12.23.0 (via corepack) checks the lockfile against supply-chain policies before every
  `pnpm <script>` and put its store at `/workspace/.pnpm-store`, outside the repo but on the
  shared mount.
- `import.meta.url` is not a file URL under Vitest's jsdom environment; the template's headers test
  runs in the node environment.
- In the mutation check, R2, R8 and R9 are shadowed: removing one alone does not open a hole
  because default-deny or fail-closed still blocks. The test catches them by the deciding rule id.
- No python3 in the image. Use node for scripted edits.

## 6. Reusable practices
- Pin from the registry and read peer ranges (`docs/playbook/pin-versions-from-the-registry.md`).
  When: any version. Evidence: the TypeScript 7 versus typescript-eslint conflict above.
- Assemble secret-shaped fixtures at runtime (`docs/playbook/assemble-secret-fixtures-at-runtime.md`).
  Evidence: gitleaks and secret-guard both report the repo clean.
- Mutation-check guards by marked rule blocks and assert the deciding rule id
  (`docs/playbook/mutation-check-guards-by-rule-block.md`). Evidence: 23 of 23.
- One policy, two checkpoints: the same `path-guard.sh` is the live hook and the post-session diff
  check, so the policy cannot drift between them.
- Dry-run on real git: the dry run creates a throwaway product repo from the template with a local
  bare remote, so worktrees, commits, trailers and pushes are exercised with no network.
