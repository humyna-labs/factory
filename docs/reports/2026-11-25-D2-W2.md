## 5. Surprises
- `git remote get-url --push origin` applies both `insteadOf` and `pushInsteadOf`;
  `git ls-remote --get-url` ignores `pushInsteadOf`. So only the first can check where a push will go
  (scratch repo test, before the read-back).
- The container's own git config already has two `insteadOf` rules (ssh to https). A blanket
  "refuse insteadOf" rule in the agents' pre-push hook would have broken every factory push.
- Bash gives a background job `/dev/null` as stdin, so `with_timeout ... gh api --input -` would
  get an empty body. I added `<&0` before the first real use. I did not run the failing variant,
  so this is from the bash manual, not reproduced.
- In the live call, `--max-turns 2` ended with `num_turns: 3` and `error_max_turns`: the Stop hook's block
  added a turn. `stream-json` shows `hook_started` and `hook_response` events for SessionStart
  but none for Stop; the Stop block shows up only as its reason text in the transcript.
- The review missed two inputs (read-back E1, E2): `scripts/labels.txt` is agent-writable and
  becomes `gh` arguments. And on the bind mount the agent can edit the scripts the owner is about to run.
- The golden runner counted every `.md` under `reports/`, so the new `INDEX.md` broke it. It now
  counts role reports only (files in per-task folders).
- One full `pnpm -r test` run had one failing hooks test file. It did not reproduce in 5 more runs. The likely cause is
  two test files creating the same symlink fixture in parallel workers. I made the fixture race-safe,
  but I did not capture the failing test's name, so the cause is presumed, not proven.
- Rewriting `settings/*.json` through `JSON.stringify` put one deny rule per line, which makes the diff look large. The content
  change is only the two new hooks.
- The work took about 27 minutes (04:11 to 04:38 UTC), well before the 05:30 window start.

## 6. Reusable practices
- Treat agent-written files as untrusted input to human-run scripts
  (`docs/playbook/agent-files-are-untrusted-input.md`). When: any script with stronger credentials
  than the agent. Evidence: A1 to A5, E1, E2; 12 of 12 guards caught by mutation.
- Make shell scripts sourceable (`main` runs only when executed) so tests can replace just the
  location check and drive the real flow with a fake `gh` on PATH. The shipped script keeps no
  test bypass. Evidence: `scripts/test/flows.test.ts`.
- Test resume with a real SIGKILL of the CLI, not a thrown error. Persist the fake adapter's state
  and make a stub that hangs once. Evidence: the W2-06 kill test.
- Events as the commit point: write the outcome event after the ledger row and before the label,
  and make a resume trust the event.
